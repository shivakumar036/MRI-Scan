# MRI-Scan

# 🧠 MRI Scan Explanation Chatbot

This is a Streamlit-based web application that helps users understand their MRI scan reports using natural language processing. It leverages the **Groq API** to provide simple, clear explanations and answer user questions related to the content of the MRI reports.

## 🚀 Features

- Paste your raw MRI report
- Ask follow-up questions
- Get clear, jargon-free explanations
- Friendly UI powered by Streamlit
- Uses the `gemma2-9b-it` model via Groq API
